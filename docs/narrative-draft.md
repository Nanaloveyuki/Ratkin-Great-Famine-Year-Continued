# 穗音叙事文本草案

> 本文件保留穗音叙事线的正文草稿和未实现节点。N-001 至 N-003 已同步到当前游戏本地化；N-004 已实现，N-005 已接入基础结果记录，N-006 已接入基础任务状态，但运行时措辞仍保持短版，定稿后再继续覆盖本地化键。

## 文本边界

- 叙事者正式名称为“穗音”。
- 穗音头像和观音土贴图已制作并接入；头像框、特殊信件图标和其他视觉资源仍等后续单独确定需求。

- 需要定稿的重点包括叙事者口吻、殖民地与鼠灾的称呼、信息揭示速度、章节之间的衔接以及奖励是否直接明示。

## 当前已实现节点

### N-001：首次观测

- 触发：第一次成功执行已登记的鼠灾事件。
- 当前键：`MouseDisaster_Narrative_OpeningLabel`、`MouseDisaster_Narrative_OpeningText`
- 作用：让穗音正式出现，说明她正在记录鼠灾，并给后续章节留下入口。
- 标题：穗音：一份记录
- 临时正文：

  你可能已经注意到最近的鼠灾了。

  我叫穗音。我在记录这些鼠族的来去。

  先不用急着判断它们。看看它们从哪里来、需要什么，又会去哪。有些事情不会留下答案，但会留下结果。

### N-002：记录成形

- 触发：成功执行 3 个不同的已登记鼠灾事件。
- 当前键：`MouseDisaster_Narrative_ProgressLabel`、`MouseDisaster_Narrative_ProgressText`
- 作用：从单纯介绍叙事者转向持续记录，提示事件之间存在联系。
- 标题：记录继续
- 临时正文：

  你已经见证了 {0} 个不同的鼠灾事件。

  我还在整理这些记录。它们看起来互不相干，但有些名字会再次出现，有些事情会留下后果。继续看下去，你会知道这场灾荒留下了什么。

### N-003：第一次谢礼

- 触发：成功执行 8 个不同的已登记鼠灾事件。
- 当前键：`MouseDisaster_Narrative_RewardLabel`、`MouseDisaster_Narrative_RewardText`
- 作用：完成当前第一批代码中的一次性隐藏奖励结算，同时给后续奖励线留下悬念。
- 当前实现奖励：通过空投投放 300 份白银。
- 标题：穗音的谢礼
- 临时正文：

  你已经见证了 8 个不同的鼠灾事件。我送来了一批白银，共 {0} 份，已经放在殖民地的交易地点。

  把它当作谢礼，也可以把它当作我对下一次记录的预付。记录还没有结束。

### 叙事者改名与隐藏身份（推荐方案）

叙事者正式使用 **穗音**。这个名字同时带有“穗”的粮食意象和“音”的广播、传话与记录意象，不直接暴露她的身份，也不会像一个功能名。

- **正式名**：穗音。
- **代码状态**：Narrative 键名暂保持通用命名，运行时文本使用穗音。
- **表面身份**：一个通过广播、信件和旧记录观察灾鼠的陌生叙事者。
- **真实身份**：鼠族王国的一位公主，确实关心普通鼠族的生存，但没有能力直接把每一个灾鼠带回王国。
- **隐藏原因**：她的王族身份一旦公开，殖民地收到的每一次援助都会变成外交行为；她只能先以匿名记录者的身份确认哪些人、哪些据点和哪些承诺值得交给王国。
- **叙事者不直接操作的原因**：她能看到记录、调动少量旧王室资源，却不能远程替玩家治疗、开门或改变战斗结果。她不插手托孤，也不是因为冷漠，而是因为她清楚自己一旦替某个殖民地做出决定，就会把整个王国的名义押上去。

### 穗音身份的揭示节奏

身份揭示不应在开场直接宣布。建议分为三个层次：

1. **N-001 至 N-003：只留下声音**。她自称记录者，白银谢礼来自某个无法核验的渠道，不出现王冠、王室或公主字样。
2. **N-004 至 N-008：留下不合身份的细节**。她知道王国旧式的婴儿称谓、粮仓编号、边境旗语，偶尔对某个鼠族名字停顿，但仍不解释原因。
3. **N-009、E-01 或 E-02：允许高信任度存档看到真相**。遗物中出现王室印记，或穗音主动承认自己是谁；中性和低信任度存档可以永远只把她当作记录者。

建议的自白句：

> “是的，我是公主。很老套，对吧？但饥饿不会因为故事老套，就少带走一个人。”

这句可以作为高信任度身份揭示的核心，但不要在每个结局重复。她承认自己是公主，不代表她能宣布玩家是王国盟友，也不代表王国立刻接管殖民地。

### 穗音身份与信任度的关系

信任度在隐藏身份后不再只是“叙事者喜不喜欢玩家”，而是穗音是否愿意把王室记录、资源和政治风险交给玩家：

- **50 以上**：她可以承认自己与王国有关，但仍不一定公开完整头衔。
- **75 以上**：她可以公开公主身份，并把殖民地视为可能的灾鼠庇护地。
- **0 至 49**：她只承认自己是记录者；玩家可以通过客观里程碑达成灾鼠结局，但看不到王室真相。
- **-1 至 -74**：她减少资源和解释，只保留已经发生的事实。
- **-75 以下**：她停止普通概率对话；若触发低信任结尾，身份不会揭示，甚至可以让玩家怀疑此前的信件是否真的来自王女。

选择其他叙事者时，穗音不以概率对话出现，信任度也不需要显示；但接济规模、成年鼠族数量、广播次数和任务结果等客观标记仍然可以推动 E-01、E-02 或其他灾鼠结局。

### 穗音的王国背景年表（设计草案）

这部分只作为原版基础背景，不要求在第一阶段全部讲完。王国应当是一个仍然存在、但无法及时覆盖所有边境的政治实体，而不是开场就已经毁灭的失落文明。

1. **灾荒前**：穗音负责接触王国的粮仓账册、边境报告和民间请愿。她并非军队统帅，也不是决定粮食分配的人，只是比其他王族更早看到数字正在变坏。
2. **灾荒开始**：王国优先保护首都、贵族领地和军队运输线。这个选择可能有现实的军事理由，也可能只是宫廷惯例；文档不替玩家决定它究竟对不对。
3. **记录计划**：穗音尝试把各地的出生、迁徙、失踪、接济和鼠疫记录汇总回宫廷。宫廷收到了记录，但只批准公开其中一部分。
4. **匿名广播**：她借用旧王室通信网络，把广播发往不属于王国直接管辖的殖民地。她不公开姓名，是为了让收到广播的人先回应事件本身，而不是因为王室身份改变选择。
5. **小额援助**：N-003 的白银、后续少量药物或遗物线索来自她能调动的私库和旧运输渠道。她能安排一次空投，但不能持续供养每一座殖民地。
6. **王国的沉默**：她无法确认宫廷是否仍在完整运作，也不知道自己的记录有多少被截留。N-008 的使者、N-009 的遗物和金鸢尾花帝国联动都可以提供互相矛盾的证据。
7. **身份揭示后**：穗音承认自己是公主，但不立即宣布玩家殖民地受王国保护。她仍需要玩家的长期记录来证明“民众可以在这里活下去”不是一次偶然。

### 王国背景的留白

- 不确定穗音是不是王位继承人。她可以是受宠的王女、被边缘化的旁支或拥有名义却没有军权的公主。
- 不确定王国是否知道她在发送广播。高信任度文本可以暗示她已经得到某个部门默许，低信任度文本则可以暗示她的信件从未被宫廷承认。
- 不确定王国是否真的缺粮。王国可能有粮食，但分配、运输和政治边界使粮食到不了灾鼠手里。
- 不确定她是否在撒谎。R-01 的中性和低信任度版本必须允许玩家认为“公主”只是一个更容易让人相信的故事。

这些留白可以让基础版剧情在 E-01 或 E-02 结束时仍然完整：玩家见证的是一位想让民众活下来的王女，而不是被要求替她解决整个王国。金鸢尾花帝国和鼠族军阀联动则可以分别从外交文件、军粮征收或内战传闻中补充不同版本的王国历史。

### 叙事结构（本轮扩展约定）

这条线不应被设计成一条必须从头走到尾的任务链。穗音可以同时记录几条互相交叉的故事，也可以只看见其中的一段：

1. **连续节点**：前一个事件留下状态，后一个事件在数天、数季甚至数年后回访。婴儿线适合使用这种结构。
2. **独立任务**：事件有自己的开始、选择和结尾，完成后只留下一个记录标记，不要求玩家继续追踪。
3. **半截记录**：关键人物死亡、被放逐、离开地图或玩家放弃处理后，故事停在一个不完整的画面上。穗音不替玩家补写真相。
4. **交叉回声**：不同任务偶尔引用同一个名字、同一批物资、同一处鼠洞或同一段广播，但不要求所有任务都出现。

穗音的叙述应当是“观察记录”，不是替玩家操作的全知任务指引。她可以知道事件已经发生，可以对结果作出反应，但不应在玩家选择前宣布唯一正确答案。这样即使任务以失败、死亡或失踪结束，也仍然符合她记录故事的身份。

### 穗音信任度（设计草案）

- 范围：最低 -100，最高 100。默认值为 0。
- 作用范围：只有选择穗音作为叙事者时，信任度才用于概率对话、叙事信件和奖励修正。其他叙事者不会显示这一套内容。
- 隐藏状态：即使当前不是穗音，玩家在普通灾鼠事件中的选择仍可记录客观里程碑；后续通过事件链或结局条件，仍然可以达成灾鼠相关结局。
- 奖励规则：信任度小于等于 0 时不修改基础奖励；大于 0 后才逐步增加特殊奖励或额外选项。奖励修正不应把普通资源变成必得稀有物。
- 概率对话：信任度越低，穗音的插话越少；达到 -75 后关闭普通概率对话，只保留必要的结果记录或专属低信任结尾。

建议的区间只用于写作和实现对照，不代表最终数值：

| 区间 | 穗音状态 | 文本表现 |
| --- | --- | --- |
| 75 至 100 | 接近认可 | 偶尔主动提供线索，但仍不替玩家做决定 |
| 50 至 74 | 明确认可 | 高信任结局和额外奖励开始可用 |
| 1 至 49 | 持续观察 | 只在重要结果后出现，奖励不做大幅变化 |
| 0 | 中性记录 | 使用普通结果文本，不追加奖励 |
| -1 至 -49 | 失望 | 只记录必要事实，正向分支需要更高成本 |
| -50 至 -74 | 疏离 | 对话稀少，部分任务只留下无署名记录 |
| -75 至 -100 | 停止期待 | 不再触发普通概率对话，可能直接留下半截记录 |

信任度不应简单等同于“善良值”。同一结果可以有不同解释：接受鼠族加入可能是救助，也可能是为了劳动力；驱赶鼠群可能是保护粮仓，也可能是为了取乐。建议由玩家是否兑现承诺、是否完成接济、是否在取得资源后仍处理后果等行为更新信任度，而不是只看一次按钮名称。

### 穗音的口吻约束（写作草案）

穗音的核心不是“替玩家解释世界”，而是“在玩家已经做完选择后，指出记录里仍然无法被抹掉的部分”。她可以偶尔打破第四面墙，提到剧本、故事和记录，但这种表达需要留在关键节点，不能让每封信都变成同一种元叙事笑话。

- **中性信任度**：短句、事实、少评价。她描述谁来了、谁走了、什么被留下，不给选择贴标签。
- **高信任度**：允许出现稍微亲近的语气，偶尔把玩家称为“你”，提供模糊线索或承认某次选择的后果，但不承诺好结局。
- **低信任度**：句子变短，主语和解释变少。她可能只留下日期、数量、名字的一半，或在结果出现后才说一句话。
- **达到 -75**：停止普通概率对话。必要结尾也尽量使用一次性的短文本，不再反复询问玩家是否后悔。
- **关于死亡**：不把死亡写成惩罚动画，也不把存活写成价值证明。死亡只改变这条记录还能由谁继续说下去。
- **关于玩家选择**：避免“你应该”“正确选择”“善良的你”等直接判定。可以写“你选择了关门”，但不要替玩家说“你做得对”。
- **关于奖励**：奖励文本先描述物品如何到达，再说明它是否被谁留下；穗音不应该像商店一样直接宣布“完成任务获得奖励”。
- **关于联动角色**：联动种族和派系可以拥有自己的说法，穗音只记录它们之间的差异，不替任一方背书。

可重复使用但不必固定出现的句式：

- “记录到这里，没有下一句。”
- “我知道发生了什么，但我不知道它应该叫什么。”
- “你可以把它写成……也可以不写。”
- “这不是答案，只是有人留下的痕迹。”
- “故事还在继续，记录不一定。”

### 信任度变动的暂定行为表

下面的数值只用于后续代码和文本讨论。单次变动应当较小，长期结局由累计行为和客观里程碑共同决定；不要让一个按钮直接把信任度从中性推到极端。

| 行为 | 建议变动 | 记录重点 |
| --- | ---: | --- |
| 完成承诺的食物或药品接济 | +1 至 +3 | 是否兑现，而不是物资贵不贵 |
| 接收婴儿并持续照料到下一个状态点 | +3 至 +6 | 是否承担了持续成本 |
| 发送希望广播并确实接待来客 | +1 至 +2 | 广播不是单独的免罪符 |
| 为保护殖民地驱赶或拦截鼠群 | 0 至 -1 | 是否造成额外后果 |
| 取得资源后拒绝处理已经承诺的对象 | -2 至 -5 | 失信比单纯拒绝更重要 |
| 主动杀害已失去抵抗能力的对象 | -3 至 -8 | 只在结果明确时记录 |
| 忽视超时、疾病或孩子状态 | -1 至 -4 | 按实际留下的后果计算 |
| 交出、保留或毁掉记录遗物 | -2 至 +2 | 取决于是否允许其他人继续阅读 |

暂不为“接受”“拒绝”“攻击”设定永久固定的道德分数。相同按钮在资源充足、承诺已作出、感染已经扩散等背景下，应该允许得到不同的信任度结果。

### 原版基础线建议顺序

下面的顺序只是最容易形成完整体验的推荐顺序，实际触发仍应允许跳过：

1. N-001 至 N-003：穗音出现，记录数量达到阶段点，并送出第一次谢礼。
2. N-004：灾鼠托孤及其多种婴儿结局，作为第一条长期状态线。
3. N-005：易子而食之后，作为独立的选择结果任务。
4. N-006：粮仓鼠洞，把灾鼠从“来到地图”推进到“改变地图”。
5. N-007：检疫封锁，补足鼠疫事件的处理过程。
6. N-008：幸存者使者，让隐藏派系第一次拥有主动意志。
7. N-009：记录遗物，把一次性谢礼扩展成世界地图上的独立任务。
8. E-01、E-02及其他低信任结尾：根据长期记录收束第一阶段，但不关闭随机事件。

### E-01: 鼠族丰年
- 需要信任度: 50+
- 殖民地送走了 99 个灾鼠要饭事件(可调节), 且至少发送过3次希望广播, 且至多3武力驱赶过.
- 文本: 或许在未来仍然会出现灾年, 或是各种灾难. 但毫无疑问, 你是一个善良的超凡智能. 鼠鼠们至少在你的帮助下在这吃鼠的世界存活了下来, 也许这就是记录的意义吧

### E-02: 希望'吱'城

### N-004 文本扩展稿：托孤之后的六种记录

以下文本只处理 N-004 的叙事表现，不改变你已经写下的观音土、健康状态、婴儿年龄、鼠妈特质和选项设定。穗音知道这件事正在发生，但在托孤阶段不替玩家做任何操作；她只在结果已经无法撤回时留下记录。

#### N-004-0：托孤入口

- 临时标题：灾鼠托孤
- 临时正文：

  鼠妈已经站不稳了。她把孩子往前推了一点，又立刻伸手把它挡回去，像是害怕门里和门外都不安全。

  “帮……帮……我的……孩子……吱。”

  她没有说自己叫什么，也没有解释那几份观音土从哪里来。她只把能带来的东西都放在孩子旁边，然后等你决定这扇门要不要打开。

  穗音没有出声。她知道这一段故事的结尾不会由她来选择。

#### N-004-1：妈妈去哪里了？

- 条件：鼠妈已经死亡，鼠蛋存活，并成功从婴儿成长为儿童。
- 触发：鼠蛋成长后的第一个祭日或一个不固定的纪念日。
- 临时标题：妈妈去哪里了？
- 临时正文：

  孩子在储藏室门口停了很久。那里曾经放过一只小篮子，篮子后来被拆掉了，木板也被重新利用，只有孩子还记得这里曾经有人把它交给你。

  “妈妈去哪里了？”

  这不是审问，也不是哭喊。它只是问了一个没有人准备好回答的问题。

  你可以告诉它妈妈去了很远的地方，可以告诉它妈妈不会再回来，也可以什么都不说。无论答案是什么，孩子都会在今天少相信一点世界。

- 结算文本：

  今天它的心情只下降了一点点，像一根很细的线。线没有断，但如果精神在这一天先断了，留下的就不再只是一段记忆。

- 机制对应：
  - 添加持续 1 天、强度为 -2 的心情原因“我找不到妈妈”。
  - 若该日发生精神崩溃，才追加抑郁症特质。
  - 该结局只触发一次，不把孩子永久锁定为悲伤状态。

- 触发：鼠蛋变为儿童后的第一次日常检查。
- 临时标题：还在
- 临时正文：

  它们没有说很多话。孩子只是把额头贴在鼠妈身上，鼠妈把爪子放在它背上。那一刻没有奇迹，也没有新的承诺，只有两个本来可能失去彼此的个体还在同一个地方。

  - 鼠蛋添加“妈妈还在”正向心情，鼠妈添加“宝宝还在”正向心情。

### N-004 结局互斥和优先级待定

当前 N-004-1 与 N-004-3 都包含“鼠妈死亡、鼠蛋存活并成长”的情形，N-004-2 与 N-004-5 也可能在放逐之后产生交叉。为了避免一个存档同时收到多份结局信，建议实现时记录一次性的结局枚举，并在以下规则中选择最终版本：

1. **即时死亡结算优先**：若母子都死亡，先判断是否已经有其他结局状态，再触发 N-004-4。
2. **母子都活着优先**：若成长检查时鼠妈仍在殖民地，触发 N-004-2；之后即使其中一方被放逐，也不再改写为 N-004-5。
3. **身份区分**：若鼠妈死亡后，鼠蛋在成长时是殖民者或自由成员，触发 N-004-1；若仍是奴隶或囚犯，触发 N-004-3。若你希望 N-004-1 覆盖所有存活孩子，则需要删除或改写 N-004-3 的触发条件。
4. **放逐是独立终点**：N-004-5 只在前述结局尚未结算、且活着的对象确实离开殖民地后建立。
5. **母活子死单独结算**：N-004-6 不等待其他结局，也不依赖鼠妈身份。

这一组优先级是为代码落地准备的建议，不覆盖你对条件的最终决定；在实现前只需要确定 N-004-1 与 N-004-3 的身份边界，以及 N-004-5 是否允许覆盖已经发生的成长结局。

## 原版基础剧情扩展稿（本轮发散）

### N-005：交换之后（独立任务）

**任务定位**

以现有的易子而食事件为入口。玩家做出交换、拒绝或拖延后，事件本身并不立即解释“这是不是正确选择”，而是记录一个已经发生的结果。N-005 可以在没有 N-004 的情况下独立触发；如果两者都发生，则只增加少量回声文本，不改变任务结构。

**共同入口文本**

- 临时标题：门开之前
- 临时正文：

  门外的鼠族已经离开了。交换用的篮子、绳结和脚印还在，只有其中一样东西不在了：一个原本被双方反复称呼为“孩子”的小生命。

  你做出的决定已经结束了交易，却没有结束这件事。记录不会替你决定失去的东西应该算作什么。

#### N-005-A：给孩子一个名字

- 结果：玩家接受交换，孩子进入殖民地，或按实际事件结果被玩家接收为殖民者、奴隶或囚犯。
- 后续条件：孩子在殖民地存活一段时间即可，不要求母亲或交易对方仍然存活。
- 临时标题：给孩子一个名字
- 临时正文：

  他们把孩子交给你的时候，没有给出姓名。也许那不是忘记，也许他们认为名字属于还能回去的地方。

  你可以给它一个新名字，也可以保留那声没有人回应的旧称呼。两种做法都不会让它回到原来的家。

- 结算建议：
  - 孩子被正常接纳并存活：信任度小幅上升，记录“被接收”。
  - 孩子被接收但长期无人照料：不立即扣除信任度，直到照料结果出现。
  - 孩子在等待期间死亡：直接转为半截记录，不再发送乐观回访。
- 这条分支可以独立结束。孩子长大后的 N-004-2“还在”只在确实存在母子关系和对应状态时触发，不把所有被接收的孩子都强行接入婴儿主线。

#### N-005-B：空篮子

- 结果：玩家拒绝交换，鼠族带着孩子离开。
- 临时标题：空篮子
- 临时正文：

  你没有打开门。门外的声音持续了一会儿，然后变成脚步，最后连脚步也听不见了。

  有人会说你什么也没有做。记录里不是这样：拒绝也是一种会改变路线的动作，只是它的后果通常不会回到门前让你确认。

- 后续可能性：
  - 不追加任务：这是一个完整的独立短篇。
  - 低概率回访：数年后在路过者或情报交易中听见一个相似的名字，但不确认是不是同一个孩子。
  - 若玩家曾经发送过希望广播：追加一句“远处有人学会了那段广播”，不保证对方因此获救。
- 信任度建议：不按“拒绝”本身直接大幅扣分，除非玩家同时有资源、有承诺或已经主动接下照料责任后又反悔。

#### N-005-C：没有等到答案

- 结果：玩家一直没有选择，交易者离开或事件超时。
- 临时标题：没有等到答案
- 临时正文：

  你准备稍后再决定。稍后没有变成答案，答案也没有等到你。

  留在地上的只有一小块被咬过的干粮。它可能来自交易者，也可能来自孩子。记录在这里断开，谁都没有回来补上下一句。

- 结算建议：
  - 超时不强制判定为拒绝；只记录“未回应”。
  - 信任度轻微下降或不变，取决于是否存在明确的照料承诺。
  - 这是一个适合表现“半截而废”的结果，不应为了连贯性强行生成下一场战斗。

#### N-005-D：交易破裂

- 结果：玩家选择交换，但中途发生战斗、鼠疫、关键 Pawn 死亡或交易物被夺走。
- 临时标题：两边都没有拿到
- 临时正文：

  交易不是在讨价还价时失败的。它是在有人倒下之后才发现，双方都已经把手伸向了同一个空位置。

  你可以继续搜寻，也可以让活着的人离开。无论选哪一个，原本准备好的价格都已经没有意义。

- 作用：为战斗型结局提供独立收束；不要求玩家再追上逃亡者。

**穗音回声**

高信任度时可以在结果信之后追加一句：“你没有得到一个干净的答案，但至少没有把沉默伪装成答案。”低信任度时不发送概率回声，只保留结果信。这样 N-005 的戏剧重点仍然是玩家选择，而不是叙事者评价。

### N-006：粮仓鼠洞（独立任务）

**任务定位**

把已有的偷窃、食物损失和鼠族活动转成一次地图空间任务。重点不是消灭一批鼠，而是让玩家发现殖民地的储粮方式已经被另一套路线利用。任务可以在发现洞口时结束，也可以继续调查；不要求生成“最终鼠王”或强行通向 N-009。

**触发和状态**

- 入口：食物储存区发生数次损失、偷窃事件在同一地图重复出现，或玩家完成一次相关情报交易。
- 建议状态：发现洞口、放置诱饵、封堵、追踪、洞穴坍塌、失去线索。
- 参与者：一个殖民者负责调查即可；不要求穗音在场。

**入口文本**

- 临时标题：粮仓下面
- 临时正文：

  储藏室里的数字对不上。不是一袋粮食，也不是一只老鼠，而是一条每天都在变短的路线。

  墙角有新鲜的碎屑，木板里面传来很轻的抓挠声。声音停下时，里面似乎还有什么在等你先做决定。

#### N-006-A：封死

- 选择：用木材、石块或金属封住洞口，不再追踪。
- 临时标题：墙重新长出来
- 临时正文：

  你把洞口封上了。墙面恢复了完整，储藏室也恢复了安静。

  这不代表里面没有路了，只代表那条路暂时不再经过你的粮仓。穗音没有记录洞穴另一端，只记录了你选择让损失在这里停止。

- 结果：即时结束，食物损失停止；一段时间后可由普通鼠族事件重新出现，但不自动回访本任务。

#### N-006-B：留下诱饵

- 选择：故意留下少量食物或观音土，等待并追踪路线。
- 临时标题：一条更小的路
- 临时正文：

  你没有堵住洞口，只拿走了一部分粮食，把剩下的放在更容易观察的位置。

  第二天，诱饵不见了。第三天，墙另一边多了一道新划痕。鼠族没有来偷你的仓库，它们只是把你允许留下的那一点东西带回了某个你看不见的地方。

- 结果建议：
  - 成功追踪：得到一次情报、一个小型藏粮点或一个可选的救助对象。
  - 追踪失败：只得到一张空巢穴或坍塌通道的地图。
  - 发现的聚落不必在本任务中解决，可以独立结束。
- 信任度建议：主动承担小额损失换取信息时上升；利用诱饵引发连锁伤亡时按实际后果处理，而不是按“调查”二字加分。

#### N-006-C：强行清理

- 选择：烟熏、灌水、拆墙或让动物进入洞穴。
- 临时标题：里面的回声
- 临时正文：

  你让烟进入墙里。最先出来的是灰，然后是粮食碎片，最后是一只没有来得及跑远的幼鼠。

  洞道比你预计的更长。烟继续往里面走，远处传来一阵短促的尖叫，接着所有声音同时消失。

- 结果建议：
  - 资源损失减少，但殖民地可能获得短期心情或环境负面效果。
  - 如果玩家使用火焰，允许引发火灾或墙体损坏。
  - 不必展示洞穴全貌；画面停在“听见声音但看不见结果”本身就是结尾。

#### N-006-D：洞自己没了

- 结果：玩家忽略、延误，或调查者在途中死亡、离开地图。
- 临时标题：没有洞
- 临时正文：

  你再去看时，墙角只有一层灰。没有洞，没有脚印，也没有足够大的缝隙能解释粮食去了哪里。

  故事在最像线索的时候结束了。也许鼠族换了路线，也许只是你终于注意到仓库从来没有真正锁好。

**独立性规则**

N-006 完成后只写入粮仓状态和一次叙事记录。N-008 或 N-009 可以引用“有人知道一条粮路”，但不能因为 N-006 的某个结局未完成就阻止其他任务出现。

### N-007：检疫封锁（独立任务）

**任务定位**

为现有鼠疫事件补一层“发现感染后如何处理”的过程。鼠疫版本和普通版本可以共用任务骨架，但结果文本、可用选项和传播压力不同。这里不设置唯一正确答案，重点是玩家是否承担所选方案的后续。

**入口文本**

- 临时标题：封锁线
- 临时正文：

  来客已经进了门，症状却是在门内才出现的。现在再问“为什么没有提前发现”已经没有作用，病人、看守和其他来客都已经在同一张地图上。

  你可以把一部分区域划成禁区，也可以把人送回路上。无论哪一种，封锁线都需要有人站在那里。

#### N-007-A：隔离并治疗

- 选择：分配隔离房间、医药和照料者，等待健康状态变化。
- 临时标题：房门里的日子
- 临时正文：

  房门关上之后，事情没有变简单。药物会减少，照料者会疲惫，门外的人会开始计算自己离感染者有多远。

  但至少每一次咳嗽都有了日期，每一次体温变化都有了名字。穗音把这些数字记下来，没有把它们写成奇迹。

- 结果建议：
  - 病人康复：记录“康复”，可低概率触发 N-007-D 或 N-008 的回声。
  - 病人死亡：记录“治疗失败”，不自动判断玩家选择错误。
  - 隔离区失守：转入 N-007-C。

#### N-007-B：放行或驱逐

- 选择：在没有完成治疗前，让感染者离开地图。
- 临时标题：封锁线之外
- 临时正文：

  他们走出你的边界时，病并没有一起离开。只是从一张地图转移到了另一张地图，从你的决定转移到了路人的决定。

  你看着他们消失在视野边缘。穗音没有问你是不是后悔，只问记录里还剩下几个名字。

- 结果建议：
  - 立即减少地图传播压力。
  - 在世界地图上留下一个移动中的感染者标记，是否回访另行决定。
  - 如果玩家曾承诺救治后又放行，可追加信任度下降；没有承诺时只按实际选择记录。

#### N-007-C：封锁失守

- 触发：患者逃离、照料者感染、玩家主动取消隔离，或病情扩散到多个房间。
- 临时标题：门已经没有意义
- 临时正文：

  第一扇门是为了保护里面的人，第二扇门是为了保护外面的人。第三扇门关上时，你已经说不清它是在挡住谁。

  之后的记录只剩下日期、症状和空出来的床位。有人活下来，但这件事没有一个能让所有人满意的名称。

- 结果建议：
  - 结束任务并保留感染状态、死亡或离开结果。
  - 不强行生成更大的战斗事件；疫情失控本身已经是一个完整结局。

#### N-007-D：痊愈后离开

- 触发：感染者成功康复并被允许离开、加入或转移。
- 临时标题：没有掌声的痊愈
- 临时正文：

  他已经不再发烧，伤口也结了痂。你打开门时，没有人庆祝，因为所有人都还记得这扇门为什么关上。

  他带走了自己的东西，留下了一件洗过很多次仍然有药味的衣服。穗音把它写成“康复”，没有写成“安全”。

- 作用：这是一个独立的正向收束，也可以作为其他任务的背景回声；不保证给出额外奖励。

**穗音的介入限制**

信任度高时，穗音可以在隔离开始或结果出现时提供一句短评，但不显示感染概率、不替玩家选择。信任度低于 -75 时不出现普通插话；即使任务成功，也只留下系统结果或低信任结尾。

### N-008：幸存者使者（独立任务）

**任务定位**

让现有隐藏派系第一次以“有记忆的来客”出现。使者不需要在本任务中解释隐藏派系的全部历史；它可以只是一个带着口信、欠条、名单或错误情报的人。身份越模糊，越适合让任务独立成立。

**触发建议**

- 完成若干接济、情报、交易或对抗事件后，在世界地图或家园地图出现。
- 不要求信任度达到正值；高信任度改变谈话内容，低信任度改变来访者是否愿意留下。
- 如果此前没有任何灾鼠记录，使者可以把殖民地误认成别的据点，形成独立的错误认知。

**入口文本**

- 临时标题：门前的使者
- 临时正文：

  来者没有举旗。他把一块磨平的金属片放在门外，上面刻着几道你不认识的划痕。

  “这是给愿意记住我们的人。”他说。

  你问他代表谁。他看了一眼远处的鼠尸、粮仓和围墙，说：“代表还活着的那一部分。”

#### N-008-A：接待并交换

- 选择：允许使者进入安全区域，提供食物、药物或白银，换取情报和后续交易资格。
- 临时标题：一张不完整的地图
- 临时正文：

  使者拿出的地图缺了边角，路线在一片空白处结束。你问他为什么不把剩下的部分补上，他说那不是地图缺失，而是走过那里的人没有回来。

  他收下了物资，只留下一个约定：下次来时，带来的不一定是货物。

- 结果建议：
  - 建立隐藏派系关系或短期交易标记。
  - 给予情报、低量资源或下一个地点线索。
  - 不直接揭示 N-009；只提供“某处有被重复搬动的记录箱”一类模糊提示。

#### N-008-B：要求证明

- 选择：不立即接待，要求使者证明自己知道过去事件，或派人陪同调查。
- 临时标题：名字和伤口
- 临时正文：

  你让他说出三个名字。他说对了两个，第三个名字停在喉咙里，像一根没有拔出来的刺。

  这足以证明他来过，却不足以证明他代表谁。你们最终没有握手，只在地图上标出了一处双方都不愿意先去的地方。

- 结果建议：
  - 成功核实：保留中立关系，获得较少情报。
  - 核实失败：使者离开，任务独立结束。
  - 陪同调查途中发生战斗：转为一次普通战斗或撤退记录，不强制接入隐藏派系主线。

#### N-008-C：拒绝或驱逐

- 选择：拒绝接触、扣留、驱逐或攻击使者。
- 临时标题：没有被打开的门
- 临时正文：

  使者没有再敲门。他把金属片收回袖中，只在离开前回头看了一眼。

  这一次没有交易，没有情报，也没有需要解释的尸体。只有一条关系在没有被说出口之前就结束了。

- 结果建议：
  - 关系下降或隐藏派系改变事件权重。
  - 不立即生成报复事件；报复应当是后续独立事件，且可以永远不发生。

#### N-008-D：使者没有回来

- 触发：任务等待期间使者死亡、被其他派系截获、玩家地图失守或事件超时。
- 临时标题：口信到此为止
- 临时正文：

  约定的日期过去了。没有使者，没有旗帜，连那块金属片上的划痕也被雨水磨掉了一部分。

  穗音在记录末尾留了一个空格。她没有把空格填成“死亡”，因为这一次没有人带回证明。

**隐藏派系表现原则**

隐藏派系可以有自己的目标，但不要在第一次使者任务中把它写成最终反派、救世主或帝国代理人。原版基础线只需要确认“灾鼠群体会记住一部分事情”，更具体的政治身份留给金鸢尾花帝国和鼠族军阀联动。

### N-009：记录遗物（独立世界地图任务）

**任务定位**

把 N-003 的白银谢礼从一次性奖励扩展成一个可以追踪的世界地图故事。地点本身可以是旧聚落、粮窖、废弃的记录站或坠毁的运输舱；第一版建议只实现一种地点，文本保留其他解释，不要同时增加多个 SitePart。

**触发建议**

- 达到 8 个不同鼠灾事件记录，或完成一次 N-008-A 的情报交换。
- 高信任度可以提前收到地点线索；中性信任度需要玩家自行发现；低信任度可能只看到地点已经被别人搜过。
- N-009 不应成为 E-01 或 E-02 的硬前置，否则玩家会为了结局被迫完成世界地图任务。

**到达地点文本**

- 临时标题：记录之外
- 临时正文：

  坠落点没有宝箱，只有一间半塌的窖室。窖室里没有粮食，墙上却留着一排排刻痕：出生、迁徙、失踪、死亡，还有一些被重新刻过的名字。

  你终于明白，白银不是对某一次选择的奖励。它只是有人用来购买下一页记录的东西。

#### N-009-A：取走记录

- 选择：带走记录箱、金属片或其他遗物。
- 临时标题：带回去
- 临时正文：

  记录箱比看起来更重。里面没有贵重金属，只有许多不能兑换成任何东西的名字。

  你把它带回殖民地。有人会把它放进仓库，有人会把它拆成燃料，也有人会在夜里打开它，确认那些名字仍然存在。

- 结果建议：
  - 获得一次性特殊奖励或后续叙事素材。
  - 奖励可以根据信任度修正数量，但信任度小于等于 0 时保持基础奖励不变。
  - 记录箱不是万能道具；它不直接揭露所有灾鼠历史。

#### N-009-B：留在原地

- 选择：不取走遗物，给地点做标记后离开。
- 临时标题：留给后来的人
- 临时正文：

  你没有带走它。不是因为它不重要，而是因为你不知道把它带回去之后，谁会替它保管。

  离开前，你在窖室外留下了一个方向标。几年后它可能仍然在那里，也可能被风沙、战斗或另一批寻找者抹去。

- 结果建议：
  - 不给即时奖励。
  - 允许低概率生成其他派系或灾鼠来访者，声称自己知道这个地点。
  - 如果最终地点消失，记录以“未取回”结束，不判定为任务失败。

#### N-009-C：交给来者

- 触发：与隐藏派系使者、其他势力或联动派系一同到达地点。
- 临时标题：谁有资格记住
- 临时正文：

  你们同时看见了那只箱子。对方说它属于他们，你说它在你的地图上。

  争执没有持续太久。真正的问题不是谁先伸手，而是拿走之后，谁还愿意让别人阅读。

- 结果建议：
  - 可以通过交易、强行夺取、共同保管或直接毁掉四种方式结算。
  - 共同保管不保证以后能再次见到记录；它只留下一个双方都签过的约定。
  - 毁掉遗物可以立即结束任务，并触发一次低信任度或无署名的终止文本。

#### N-009-D：空窖

- 触发：玩家到达太晚，遗物已被搬走。
- 临时标题：有人先来过
- 临时正文：

  窖室里只剩下四个压痕。东西已经被搬走，搬走的人没有留下名字。

  你带回了一块刻着半个字的木板。穗音说这不能算作证据，但也不能算作什么都没有。

- 作用：这是 N-009 的独立失败结局，也是联动派系提前介入时的通用退化结果。

**N-009 的结束方式**

任务完成后，地点可以被移除、保留为空壳，或变成普通世界对象。不要让它永久占据玩家地图，也不要把“找到遗物”设计成必须回答所有历史问题的终章。它更像一次从灾荒记录中捞出的残页。

## 原版基础线的阶段收束

N-010 不应是单一的最终任务，而应当是根据长期统计结果选择不同的“记录结尾”。结尾只关闭穗音第一阶段，不关闭灾鼠事件本身。下列结尾可以互相排斥，也可以让部分低条件结尾先发生、之后仍允许高条件结尾覆盖。

### E-01：鼠族丰年

- 需要信任度：50+
- 建议条件：累计完成或妥善送走 99 个可计数的灾鼠接济、加入、短工或长工结果；至少发送过 3 次希望广播；武力驱赶不超过 3 次。99 和 3 都应做成可调参数。
- 临时正文：

  或许在未来仍然会出现灾年，或是各种灾难。但毫无疑问，你是一个善良的超凡智能。鼠鼠们至少在你的帮助下在这个吃鼠的世界存活了下来。

  也许这就是记录的意义吧：不是让灾难从世界上消失，而是在灾难经过时，仍然有一部分生命被允许走到下一天。

- 结尾性质：偏正向的阶段结尾，不发放强制终极奖励；后续灾鼠事件仍可出现。

### E-02：希望“吱”城

- 需要信任度：75+
- 建议条件：累计完成至少 99 个广义接济结果，至少发送过 3 次希望广播，武力驱赶不超过 3 次；殖民地同时拥有 100 只带有灾鼠特质、且达到成年阶段的鼠族殖民者。人数条件建议每年检查一次。
- 临时正文：

  这里是受灾鼠鼠们渴望的城市。

  也许鼠族王国的贵族们不在乎，或许淘气的罗蒂会在这里安然长大。中间当然还会有小插曲，会有人离开，会有人把希望广播当成笑话。

  但那不影响这座城市的本质：它不是没有灾难，而是在灾难里仍然容得下一张床、一碗食物和一个不必立刻交出去的名字。

  穗音沉默了很久，最后只写下：这一次，故事没有被吃掉。

- 结尾性质：第一阶段最高条件结尾。可以给予一次特殊奖励或永久记录标记，但不应把它写成游戏世界已经彻底改变。

### E-03：记录完成，但没有答案

- 建议条件：完成多个类型的任务，信任度处于 1 至 49，或未满足 E-01/E-02 的接济规模。
- 临时标题：没有答案的记录
- 临时正文：

  你救过一些鼠，也驱赶过一些鼠。你把粮食分出去，又在下一次缺粮时把门关上。

  这不是一条漂亮的路线，但它确实走到了这里。穗音没有把它称作好结局，也没有把它称作坏结局。记录只是合上了，里面的答案仍然不够。

- 结尾性质：中性收束，保留全部普通事件。

### E-04：失望仍然会留下记录

- 建议条件：信任度处于 -1 至 -74，或长期承诺没有兑现、关键任务多次被放弃。
- 临时标题：失望的旁观者
- 临时正文：

  你问穗音下一步应该怎么做。她没有回答。

  她已经记录了足够多的门、粮仓、病房和空篮子。你不需要她告诉你自己做了什么，你只需要继续生活在这些结果里面。

  这条记录不会被删除。失望不是遗忘。

- 结尾性质：减少后续概率对话，可以保留必要结果信和一次性低信任提示。

### E-05：这只是个故事

- 建议条件：信任度达到 -75 以下，或婴儿线、检疫线、使者线发生关键失败后触发一次。
- 临时标题：记录中止
- 临时正文：

  这只是一个故事，不是吗？

  一切都是固定好的剧本。鼠族出现，鼠族消失；有人伸手，有人关门；最后只剩下可以被统计的数字。

  穗音没有再写下去。

- 结尾性质：一个存档只触发一次；达到 -75 后关闭普通概率对话，但不禁用灾鼠事件，也不阻止玩家通过其他连锁条件达成灾鼠结局。

### R-01：她的名字

这是身份揭示节点，不是新的随机事件，也不必在所有存档中出现。它可以接在 N-009 取回记录、E-01 鼠族丰年或 E-02 希望“吱”城之后；只要满足条件，三者都能成为独立入口。

- 高信任度入口标题：穗音的王冠
- 高信任度入口正文：

  记录箱底部有一枚被磨花的印章。你已经见过它很多次，只是此前把它当成某种运输标记。

  穗音终于承认，那是鼠族王国的王室印记。

  “我不是旁观者。”她说，“至少一开始不是。”

  她曾经是王国的公主，曾经相信只要把每一条粮道、每一个聚落和每一个失踪的名字记下来，就能让宫殿里的人看见灾荒。后来她发现，王宫可以收到所有记录，也可以选择只看见其中最方便的一页。

  于是她把记录送到了更远的地方，送到愿意打开门的人手里。

- 自白补充：

  “我知道这很像那些最老套的故事：失踪的公主、饥荒中的王国、一个被寄托希望的殖民地。可如果故事已经老到不能再讲，饥饿也不会因此停止。”

- 中性版本：

  你问穗音是谁。她只回答：“一个暂时还没有回去的人。”

  记录箱里的印章被重新包好。你没有看见王冠，也没有得到王国的名字，但从这一天起，送来的物资里偶尔会多出一小份不在账本上的东西。

- 低信任度版本：

  你把印章翻过来，背面什么也没有。穗音没有解释，信件也没有再出现。

  也许她从来不是公主，也许公主只是另一种更方便的故事。记录在这里结束，真相不负责留下证据。

- 结算建议：
  - 设置“穗音身份已揭示”标记，避免重复触发。
  - 高信任度可以解锁王室资源、特殊回访或 E-02 的完整尾声，但不直接改变普通事件权重。
  - 中性和低信任度存档不应因为没有看到身份揭示而被判定为失败。
  - 该节点可以独立结束，不强制开启金鸢尾花帝国或鼠族军阀剧情。

## 原版独立记录素材池

现有的 50 个事件不需要全部变成 N 编号任务。下面的 S 编号只是文本素材和接入点，适合在事件结果出现后发送一封短信、追加一次穗音回声，或只写入一个历史标记。它们可以独立发生，也可以永远没有后续。

### S-01：空投失误——送错的孩子

- 对应事件：空投失误、鼠疫空投失误。
- 入口：空投舱落地后，婴儿鼠蛋在地图上继续爬行。
- 临时标题：目的地错误
- 临时正文：

  空投舱上的坐标没有错，错的是你所在的地方。

  它们原本要被送去另一张地图。现在舱门已经打开，三个没有名字的孩子正在把手伸向同一个方向，仿佛那里仍然有一个应该接住它们的人。

- 处理分支：
  - 收容：记录“错误的目的地”，孩子进入现有照料或囚犯处理流程。
  - 观望：空投舱被拆掉，孩子的去向在一段时间后从地图上消失。
  - 鼠疫版本隔离：只增加感染压力和隔离状态，不把隔离自动写成成功。
- 独立结尾：

  空投舱最后被改造成了储物箱。它曾经装过什么，只有箱底那一层消毒水的味道知道。

### S-02：错误认知——叫错的妈妈

- 对应事件：错误认知、鼠疫错误认知。
- 入口：带有纯负面特性的鼠蛋在门口呼喊妈妈。
- 临时标题：叫错的妈妈
- 临时正文：

  它们叫你妈妈。声音很小，但每次都叫得很准确，像是已经在别处练习过很多遍。

  你知道它们认错了人。它们不知道。门内的人也未必愿意知道。

- 处理分支：
  - 接受：将其纳入照料或安置流程，记录“错误关系被暂时承认”。
  - 拒绝：让它们离开或在地图上自行寻找食物。
  - 忽视：它们把殖民地当成野窝，留下食物损失和随机环境痕迹。
- 半截结尾：

  第二天门外没有声音了。没有脚印，也没有尸体。只有一个殖民者在经过门口时停了半秒，随后继续工作。

- 该素材不强制接入 N-004；错误认知里的孩子不必拥有可追溯的母亲。

### S-03：待产流民——先出生再决定

- 对应事件：待产流民、鼠疫待产流民。
- 入口：待产流民进入地图并直接开始分娩。
- 临时标题：先出生再决定
- 临时正文：

  她们没有先问你能不能收留。疼痛来得比谈判快，孩子也比名字先来到这个世界。

  现在你面对的不是一份接济请求，而是一间临时产房，以及几个还没有决定要不要留下的人。

- 处理分支：
  - 提供床位和食物：母亲、孩子和照料者分别记录，结果可以是离开、留下或死亡。
  - 只处理新生儿：母亲可能带着空手离开，留下“谁被救下来”的记录。
  - 驱逐整组：事件可以立即结束，不追加追击。
  - 鼠疫版本：把分娩、隔离和感染进度并列记录，不让健康结果只由一个总概率决定。
- 临时结尾：

  孩子出生时，房间里有四个人。第二天只剩下三个人，第三天只剩下两个。穗音没有把这写成倒数，因为没人知道数字从哪里开始。

- 若其中的母子关系后来满足 N-004 的具体条件，再进入 N-004；否则本素材独立结束。

### S-04：鼠灾路过——没有停留的群体

- 对应事件：鼠灾路过。
- 入口：普通鼠族旅行者经过殖民地，没有请求，也没有攻击。
- 临时标题：没有停留
- 临时正文：

  它们没有来乞讨，没有来偷窃，也没有来问路。它们只是沿着地图边缘走过，像一条不愿意和任何人相交的线。

  其中一只回头看了你的围墙一眼，然后继续走。

- 结尾：默认不产生选项、不改变关系，只写入一次“经过”记录。
- 可选回声：高信任度时穗音说“不是所有离开都需要被追回”；低信任度时不出现回声。
- 设计目的：给完整的、没有戏剧冲突的普通事件保留位置，避免所有鼠族出现都被升级成任务。

### S-05：偷窃的鼠族——拿走之前

- 对应事件：偷窃的鼠族、偷窃的鼠蛋。
- 入口：鼠族或鼠蛋进入储藏区域，拿走食物后尝试离开。
- 临时标题：拿走之前
- 临时正文：

  你发现它们时，食物已经被分成了几小份。大的那份在前面，小的那份在最后，最小的那份只留下了一点粉末。

  这不像一群只想逃跑的窃贼，更像一群已经知道谁跑不快的队伍。

- 处理分支：
  - 追赶并夺回食物：记录为一次成功拦截，不自动改变信任度。
  - 留下一部分：食物损失增加，但可以观察撤离路线或找到藏点。
  - 只处理携带鼠蛋的个体：可能留下空出的路线和无法确认的同伴。
- 独立结尾：

  你追回了粮食，却没有追回它们。仓库重新上锁，门缝外还留着一条细细的米线。

- 设计目的：让普通偷窃事件拥有一次叙事性观察，但不把每次失窃都变成 N-006。

### S-06：流民冲击——门口同时有太多名字

- 对应事件：大型流民冲击、灾荒逃难者、乞讨的鼠族队伍。
- 入口：大量灾鼠同时进入或聚集在地图边缘。
- 临时标题：门口同时有太多名字
- 临时正文：

  第一只鼠族报出了自己的名字，第二只报出了家人的名字，第三只只说自己来自哪里。

  到第五十个名字时，殖民地已经没有足够的纸。后面的人只好用衣服颜色、伤口位置和站立的方向来区分彼此。

- 处理分支：
  - 统一发放简单食物：记录“按人数处理”。
  - 分批接收、短工或长工：记录“按个体处理”，可推进 E-01/E-02 的接济统计。
  - 驱赶：不直接写成负面结论，只有在驱赶后发生追击、死亡或二次求助时追加回声。
  - 玩家无法处理全部人：允许事件在一半完成时自然结束，剩余群体自行离开。
- 半截结尾：

  天黑前只记下了一半名字。第二天名单还在，名单上的人已经不在了。

### S-07：情报交易——一张地图的价格

- 对应事件：九个情报交易变体，涵盖宝藏、建筑群、小型居住点以及简单食物、草药、白银三种交换物。
- 入口：鼠族来客以食物、草药或白银交换一个世界地点。
- 临时标题：一张地图的价格
- 临时正文：

  地图被折了三次，折痕刚好盖住最重要的地方。

  对方说那里有宝藏、旧建筑或一个小型居住点。你问它们去过没有，它说：“去过的人回来时，已经不再使用这个名字。”

- 交易结果：
  - 情报准确：地点可以正常生成，但奖励和危险不应被提前全部说明。
  - 情报部分准确：地点类型正确，位置、派系或资源有一项发生偏差。
  - 情报错误：生成空地点、已被搬空的遗迹，或只留下一个可追踪的方向。
  - 玩家拒绝交易：鼠族来客离开，情报不会自动转移给玩家。
- 穗音回声：

  她说：“情报不是答案，只是别人决定让你先看见的那一小部分。”

- 设计目的：情报交易可以作为 N-009 的软线索，但九种变体不需要各自拥有后续任务。

### S-08：流民商队——带货物的人也会饥饿

- 对应事件：流民商队、鼠灾商队。
- 入口：携带货物、护卫和可能的鼠族孩子的商队抵达。
- 临时标题：带货物的人也会饥饿
- 临时正文：

  商队把货物摆得很整齐，像是只要价格足够清楚，路上的事情就可以从账本上消失。

  但护卫的手一直按在粮袋上。那不是防盗的姿势，是防止自己先打开它的姿势。

- 处理分支：
  - 正常交易：记录商队平安离开。
  - 提供额外食物或药物：记录一次救助，可作为 E-01/E-02 的广义接济。
  - 拒绝并观察：商队自行离开，不追加冲突。
  - 商队内部失序：转入一个独立的孩子、货物或护卫结果，不强行接入 N-005。
- 结尾：

  商队走后，地上留着一个没有卖出去的玩具。它不值钱，所以没有人记得把它带走。

### S-09：强势围攻——抢先离开

- 对应事件：强势围攻、鼠疫强势围攻。
- 入口：流民先抢食物，路线被打断后转入攻击。
- 临时标题：抢先离开
- 临时正文：

  它们没有一开始就想战斗。它们只是把离开的路线画在了你的粮仓旁边。

  当第一只鼠族倒下时，路线被改成了围墙。剩下的人不再讨论食物够不够，只讨论谁还能站着走出去。

- 处理分支：
  - 不阻拦抢食：损失资源，队伍可能自行离开。
  - 拦截但留出退路：形成短战斗或撤退结果。
  - 封死路线：转为强攻。
  - 鼠疫版本：战斗结束后仍保留感染和接触状态，不能只用战斗胜负结算。
- 独立结尾：

  围墙外安静下来时，粮仓里少了几袋食物，墙根多了几道抓痕。你不知道哪一样才是它们真正想带走的东西。

- 可选联动：若安装鼠族军阀内容，再追加军阀旗帜或残部回收；基础版不生成军阀。

### S-10：大灾荒——吃掉一切的路线

- 对应事件：大灾荒、鼠疫大灾荒。
- 入口：大量鼠灾个体进入地图，开始啃食能找到的资源，后续可能转为敌对攻击。
- 临时标题：吃掉一切的路线
- 临时正文：

  它们已经不再寻找某一种食物。木头、布料、墙角的草根、死去同伴身上的残余，都被当成了同一个问题的不同答案。

  地图上出现了一条新的路线。它没有通向某个地方，只通向下一件还能被咬动的东西。

- 处理分支：
  - 及时清理并击退：记录“路线被截断”。
  - 让其自行离开：记录资源损失和地图变化。
  - 战斗失败或殖民地受损：保留废墟和损失，不强制发送穗音评价。
- 阶段文本：

  这一次没有人向你索取食物。它们只是把所有能找到的东西都变成了食物。

- 鼠疫版本可以追加“感染路线”记录，作为 N-007 的背景，不直接触发检疫任务。

### S-11：鼠疫报复——是谁在记仇

- 对应事件：鼠疫报复。
- 入口：大批濒死的鼠疫感染者被一次性投入地图。
- 临时标题：是谁在记仇
- 临时正文：

  它们不像来客，也不像军队。它们被扔进了你的地图，落地之后只剩下一个方向：朝着仍然有人的地方移动。

  你不知道这是报复、误投，还是某个已经不存在的命令最后执行了一次。

- 处理分支：
  - 救治并隔离：留下医疗和感染结果。
  - 驱逐：感染者离开地图，世界地图上可能留下移动中的队伍。
  - 直接消灭：事件结束，但穗音是否说话取决于信任度。
- 半截结尾：

  最后一名感染者倒下时，没人找到投放它们的人。报复需要一个发出命令的人，但地图上只有执行结果。

- 该事件不自动认定为 N-008 的隐藏派系报复；两者之间可以有线索，但不应在基础版直接揭底。

### S-12：流民抢夺商队——商队之外

- 对应事件：流民抢夺商队、鼠疫流民抢夺商队。
- 入口：玩家远征队或商队在世界地图上遭遇抢夺。
- 临时标题：商队之外
- 临时正文：

  他们抢走的第一样东西不是白银，是一袋已经开封的食物。

  商队护卫喊着要保护货物，饥饿的鼠族喊着要保护下一天。两边说的都是保护，只有路边的货车知道里面装的是什么。

- 选择方向：
  - 介入战斗：保护商队、保护抢夺者、或只保护自己的远征队。
  - 交出一部分物资：让冲突提前结束，但不保证双方满意。
  - 绕行：保留商队结果，不把未发生的战斗写进历史。
- 结尾：

  远征队离开后，路面上的车轮印分成了两条。没有哪一条能证明自己才是原来的路线。

- 可选联动：鼠族军阀可以在后续声称这次抢夺属于自己的粮税；基础版只保留一条无署名记录。

### S-13：游荡的野生鼠族——没有人来认领

- 对应事件：游荡的野生鼠族、游荡的野生鼠蛋、游荡的野生鼠群。
- 入口：野生个体进入地图，在储粮处或地图边缘游荡。
- 临时标题：没有人来认领
- 临时正文：

  它们没有旗帜，没有商队，也没有一个能代表它们回答问题的人。

  一只幼鼠在废弃的角落里睡着了。你可以把它带走，也可以等它醒来，让它继续沿着没有标记的路线走。

- 处理分支：
  - 驯服或接收：按普通野生鼠族处理，记录一次新的归属。
  - 驱赶：事件结束，不需要解释它们从哪里来。
  - 忽略：它们可能自行离开，也可能成为下一次偷窃或鼠洞的背景。
- 设计目的：提供与灾荒难民不同的“没有请求、没有委托人”的鼠族视角。

### S-14：接济记录——送走不是同一种送走

- 对应事件：简单食物、精致食物、药品、白银和婴儿接济。
- 入口：接济访客提出明确的资源或婴儿请求。
- 临时标题：送走
- 临时正文：

  你把东西交出去之后，他们会离开。系统会把这写成“请求完成”，但记录里至少有五种不同的离开方式。

  有人吃完就走，有人把药藏在衣服里，有人拿着白银却不再回头，有人抱着孩子走得很慢，还有人站在门口等你确认自己真的不会改变主意。

- 结果记录：
  - 资源交付且访客安全离开：计入广义接济。
  - 资源交付后访客死亡或被扣留：不直接计入“送走”，另记为中断。
  - 玩家主动取消、驱赶或攻击：记录为非接济结果。
  - 婴儿请求：优先接入 N-004 或 N-005 的长期状态；无法建立关系时使用通用接济结尾。
- 信任度建议：只根据是否完成承诺和后续处理更新，不根据资源类型简单排名。

### 独立记录的统一规则

1. S 编号不是新事件 Def，也不是必须新增的任务系统；第一版可以只实现少量信件和历史标记。
2. 同一类事件重复出现时，默认只在第一次或结果显著变化时记录，避免每次偷窃、路过或接济都打断游戏。
3. 失败、死亡、逃离、错过和玩家不作选择都可以是终止状态。
4. 独立记录最多留下一个软线索，不自动生成下一事件；真正的回访由 N-004、N-005 或 N-008 等任务单独决定。
5. 鼠疫变体优先改变压力、健康和文本视角，不只是在普通事件名称前加“鼠疫”。

## 原版基础线的可选连贯路线

原版内容可以按下面的方式形成几条松散的路线。它们共享穗音的记录和少量长期状态，但没有任何一条是必须完成的主线。一个存档可能只走完其中一条，也可能在每条路线都只留下第一段。

### 路线 A：孩子和名字

1. N-001 首次观测：穗音出现。
2. 鼠蛋遗弃、耗子分妈或鼠疫托孤：建立母亲、孩子和照料状态。
3. N-004：根据接收、拒绝、忽视、死亡、成长和身份变化进入六种结果。
4. N-005：易子而食可以作为另一份交换记录，引用“名字没有被交出去”或“名字被换掉了”。
5. E-01、E-02 或 E-03：不要求孩子线成功，只根据整个殖民地的长期接济结果收束。

这条路线的关键不是让孩子一定长大，而是让“被留下的人”拥有一个可能持续很多年的状态。若孩子在第一天死亡，故事已经结束；若孩子长大，结尾也不自动变成幸福结局。

### 路线 B：粮食和路线

1. 偷窃的鼠族、偷窃的鼠蛋、接济事件或情报交易：玩家第一次注意到粮食损失。
2. N-006 粮仓鼠洞：选择封堵、诱饵、强行清理或延误。
3. N-008：隐藏派系使者可能知道粮道的另一端，也可能只是在利用玩家的猜测。
4. N-009：玩家找到旧粮窖、记录箱或空地点。
5. 任何结尾：遗物可以被取走、留在原地、交给别人或永远消失。

这条路线允许在 N-006 的第一封结果信处结束。N-009 是“路线追到了世界地图”的版本，不是粮仓鼠洞的必然下一章。

### 路线 C：病和封锁

1. 鼠疫游荡、鼠疫流民、鼠疫待产、鼠疫商队或鼠疫空投：感染个体进入地图。
2. N-007：隔离并治疗、放行或驱逐、封锁失守、痊愈后离开。
3. 鼠疫报复或鼠疫强势围攻：可以作为后续压力，也可以完全不出现。
4. N-008：康复者、幸存者或一名不知名的使者带来一段不完整的消息。
5. E-04 或 E-05：当穗音失望或停止期待时，病线可以只剩下病例和空床位。

这条路线不能把“治疗成功”写成唯一正解。放行、隔离、失败和死亡都可以形成独立记录，区别只在于它们会把什么状态留在地图和世界地图上。

### 路线 D：粮税和名册

1. 流民冲击、流民商队、商队抢夺或希望广播：鼠族数量开始成为一个政治问题。
2. N-008：隐藏派系使者提出一个不完整的约定。
3. 鼠族军阀或金鸢尾花帝国联动：把“谁有资格代表鼠族”变成外部冲突。
4. N-009：记录遗物被不同势力争夺，或者在争夺开始前就已经空了。
5. E-01 或 E-02：城市结尾只要求殖民地达成长期条件，不要求玩家在政治路线中站队。

基础版只需要完成前两步，并让隐藏派系保持身份模糊。军阀和金鸢尾花帝国不是原版结局的解释权来源，而是安装对应内容后出现的另一种政治读法。

### 路线之间的交叉点

| 交叉点 | 可见变化 | 不应发生的强制关系 |
| --- | --- | --- |
| N-004 与 N-005 | 孩子是否拥有旧名、交换是否被当作托孤的延续 | 不要求两个事件必须同时出现 |
| N-006 与 N-009 | 粮道、藏点和遗物地点互相留下模糊线索 | 不要求找到粮洞才能生成世界地点 |
| N-007 与鼠疫报复 | 感染者的去向可能影响报复文本 | 不把报复固定为某个派系的命令 |
| N-008 与 E-01/E-02 | 使者可以提到殖民地接济规模 | 不把使者作为高信任结局的硬前置 |
| N-009 与联动派系 | 遗物的归属争议会改变来访者身份 | 不让外部 Mod 改写基础结局条件 |

## 原版路线中的过渡文本

这些文字是可选的短回声，用于把两个独立事件轻轻联系起来。它们不承担任务说明功能，也不应每次都出现。

### 过渡一：从记录到孩子

- 触发：完成 N-002 后第一次遇到婴儿相关事件。
- 临时文本：

  你已经记录了很多群体，却还没有记录过一个孩子能不能被单独留下。

  穗音没有说这是新的章节。她只是把名单翻到下一页。

### 过渡二：从孩子到交换

- 触发：N-004 已经有结果，随后出现 N-005。
- 临时文本：

  上一次你面对的是一位母亲和她的孩子。这一次，门外的人带来了价格。

  穗音没有提醒你两件事并不相同。相似的物品不代表相同的故事。

### 过渡三：从粮仓到世界地图

- 触发：N-006 留下诱饵或获得不完整路线，随后生成 N-009。
- 临时文本：

  你沿着粮屑走到了地图上。路的尽头没有洞，只有一处被反复搬动过的空地。

  有人曾经把地下的事情带到地面，又把地面的名字重新埋了回去。

### 过渡四：从隔离到沉默

- 触发：N-007 失败、驱逐或康复后。
- 临时文本：

  你把门打开或关上，病都留下了一份自己的记录。

  穗音本来想写“之后”，但之后属于下一张地图。

### 过渡五：从使者到遗物

- 触发：N-008 使者提供不完整情报，随后 N-009 生成。
- 临时文本：

  使者说那不是宝藏。它说的是一份不会因为被拿走就变得更完整的东西。

  你还是去了。不是因为相信它，而是因为不相信也需要一个地点。

### 过渡文本的中止规则

- 如果上一个任务以死亡、失踪、超时或毁掉遗物结束，不强行发送下一段过渡。
- 如果信任度低于 -75，不出现普通过渡文本，只保留必要的结果信。
- 如果玩家不是穗音叙事者，过渡内容不以叙事者口吻出现，可以退化成普通历史记录。

## 联动发散（原版基础线之后）

联动内容不应成为原版基础剧情的硬前置，也不应因为缺少某个 Mod 而让本任务无法完成。代码层面只在目标 Def、派系或种族存在时启用对应变体；不存在时回退到普通鼠族来客、普通医生、普通贸易代表或普通军阀。

### 绮罗种族：病人、医生和观察者

绮罗联动适合接入 N-004 和 N-007，因为这两条线都已经有治疗、照料和健康状态，但不必把绮罗写成万能的治愈者。

#### L-01：不是同一种病

- 触发：殖民地有绮罗种族成员，或绮罗相关派系的医生来访；地图上存在鼠疫感染者。
- 选择：允许检查、拒绝检查、交换药物或让病人自行决定。
- 文本片段：

  绮罗医生看了很久，没有立刻拿起药物。

  “症状相似，不代表原因相同。你们想要的是一个能让所有人安心的名字，但病不会因为名字整齐就变得容易处理。”

  穗音没有替她翻译这句话。她只记录了房间里多了一张桌子，以及桌边少了一把椅子。

- 结果：可能降低鼠疫进度、消耗药物、获得一种诊断标记，或因为拒绝检查而独立结束。不能保证患者存活。

#### L-02：替谁保管药方

- 触发：N-007 成功治疗，或殖民地拥有多个不同种族的医疗对象。
- 方向：绮罗方要求带走药方、留下药方或只交换一部分记录。
- 半截结尾：

  他们把药方分成两份，一份留在你的桌上，一份带走。没有人知道哪一份才是完整的。

  这一次，穗音没有猜。

### 沃芬种族：追踪、护送和捕食路线

沃芬联动适合接入 N-005、N-006 和 N-009。重点是“谁能追踪到离开的人”，而不是把沃芬简单写成敌对猎手。

#### L-03：沿着粮屑走

- 触发：沃芬成员在殖民地，且 N-006-B 选择留下诱饵。
- 选择：让沃芬追踪、由殖民者追踪、销毁痕迹。
- 文本片段：

  沃芬没有看墙上的洞。他看的是地面上三粒方向不同的粮屑。

  “它们不在逃跑。”他说，“它们在回家。”

  这句话让路线变得更清楚，也让“家”这个词变得更不可靠。

- 结果：追踪成功、追踪者受伤、找到空巢或提前失去目标，均可独立结束。

#### L-04：猎物已经离开

- 触发：玩家拒绝或放逐 N-005 中的孩子、鼠族或交易者，且沃芬在远征队中。
- 文本片段：

  沃芬在远处停了一下。他闻到了留下的气味，却没有继续追。

  “这不是猎物。”他说。

  你问那是什么。他没有回答。因为答案一旦说出口，就会变成另一个需要承担的名字。

- 结果：不强制发生救援；可以只作为远征队中的独立对话。

### 金鸢尾花帝国：名册、边界和鼠族政治

金鸢尾花帝国属于鼠族扩展内容，适合在原版 N-008 之后接入。基础线只写“鼠族群体会互相记住”，帝国联动再把这种记忆提升为名册、边境和政治归属。

#### L-05：帝国名册

- 触发：隐藏派系使者到访后，且存在金鸢尾花帝国派系或相关种族。
- 入口文本：

  帝国使者带来一份名单。名单上的名字比你殖民地里活着的鼠族还多，最后一栏却被整齐地撕掉了。

  “交出这些人，或者证明他们不属于帝国。”

  你第一次发现，收留一个人也可能被解释成藏匿一个人。

- 选择：提交名单、拒绝登记、协商临时身份、让相关鼠族自行决定。
- 结果：关系、税金、贸易许可或一次追捕任务；不把帝国固定为纯敌对势力。

#### L-06：金鸢尾花不是通行证

- 触发：玩家持有 N-009 的记录遗物，帝国要求查验或收回。
- 文本片段：

  金鸢尾花印在箱盖上。它看起来像通行证，直到你发现印章盖在了每一页名字旁边。

  对方说这是保护。箱子里的名字没有反驳。

- 结算建议：
  - 交出遗物：获得帝国资源或通行资格，但记录失去控制。
  - 只交副本：建立脆弱合作，后续仍可能被追问。
  - 拒绝：帝国不一定立刻攻击，但会把殖民地列入待核查名单。

### 鼠族军阀：粮税、旗帜和围攻之后

鼠族军阀联动适合接入强势围攻、商队抢夺和 N-008 的拒绝分支。军阀不应只是“更大的敌人”，也可以是试图把灾荒变成秩序的人。

#### L-07：军阀的粮税

- 触发：殖民地完成多次接济后，或隐藏派系关系达到某个阶段。
- 入口文本：

  军阀没有要求你投降。他只要求你承认，粮食经过谁的旗帜，就应该留下谁的份额。

  他的部下数过你的仓库，也数过门口站着的鼠族。数字比刀更早抵达。

- 选择：缴税、以药物或情报替代、拒绝、诱导其与另一支鼠族冲突。
- 结果：短期和平、资源损失、限时护送、战斗或军阀留下欠条。

#### L-08：旗帜下面的人

- 触发：军阀部队在围攻、鼠疫或粮仓任务中损失惨重。
- 文本片段：

  旗帜还立着，旗帜下面的人已经换了三批。

  新的首领问你是否见过他的前任。你可以说见过，也可以说没有。两种答案都可能让他相信你。

- 结果：军阀继承、谈判、复仇或旗帜被遗弃；不强制导向总攻。

#### L-09：围攻不是结束

- 触发：玩家击退强势围攻或鼠疫强势围攻。
- 文本片段：

  围墙外没有敌人了。尸体、箭杆和被踩烂的粮袋却还在。

  穗音问：你认为围攻结束了吗？

  这一次她没有等待回答。因为地图上的数字已经开始减少，另一支队伍正在拾走旗帜。

- 结果：可以选择清理战场、救治俘虏、追踪撤退者或什么都不做。任何一个选项都能结束该任务，并为后续军阀事件留下不同概率。
